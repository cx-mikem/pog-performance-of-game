# phaser-pog documentation

POG (**P**erformance **O**f **G**ame) is a drop-in debug overlay for Phaser 3.60+ and Phaser 4.x games. These pages cover everything beyond the [top-level README](../README.md).

## Contents

- [Getting Started](./getting-started.md) — install, register the plugin, toggle the overlay
- [Options](./options.md) — every `PogOptions` field, with defaults and examples
- [Inspectors](./inspectors.md) — Scenes, Culling, Entities, Sprites, and the global registry
- [Network Adapters](./adapters.md) — Colyseus, raw WebSocket, and custom transports
- [Session Export](./session-export.md) — JSON schema and how to use exports in bug reports
- [Production Builds](./production.md) — gating, tree-shaking, and overhead notes
- [Architecture](./architecture.md) — how the pieces fit together
- [FAQ](./faq.md) — common questions and gotchas
